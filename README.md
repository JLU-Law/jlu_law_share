# JLU Law Share

**让学习资料自由流动。**

一个由吉林大学法学院学生自发建设的法学学习资料共享平台。

我们希望把分散在不同年级、不同课程中的学习资源整理起来，让每一份愿意分享的资料，都能帮助到更多同学。

## 项目内容

- **课程目录**：按课程、授课教师查找课程信息。
- **课程 PPT**：整理和共享允许公开传播的课程课件。
- **历年试题**：收集、整理学生自愿分享的期末试题回忆版。
- **学习资料**：欢迎分享原创笔记、思维导图及其他学习资源。

## 如何参与

**查找资料**

进入网站，搜索课程名称或教师，浏览相关课程及资料。

**分享资料**

将愿意公开分享的学习资料发送至项目投稿邮箱。可以匿名投稿，也可以自愿署名。

**共同维护**

欢迎补充课程信息、纠正资料错误，或参与资料整理与网站建设。

## 项目理念

免费共享，自愿贡献，尊重原创。

希望让知识在不同年级之间持续流动。
